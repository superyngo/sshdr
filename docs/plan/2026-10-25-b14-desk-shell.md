# B14 桌面外殼（Desktop shell）計畫
Status: Landed (2026-10-25，分支 `b14-desk-shell`)
Date: 2026-10-25
Source: [ADR 0006](../adr/0006-tui-desktop-as-separate-client.md)；[ADR 0007](../adr/0007-desktop-tasks-are-workspaces.md)；[B13 結果](../audit/2026-10-24-b13-desk-spike.md)；Backlog B14

## 1. 目標

把 B13 spike 變成可日常使用的 `herdr desk`（只做本機 **Server**；遠端是 B22/B15）：
每個 workspace 是一個 **Task**、每個 tab 是一個 **Terminal Window**；有 **Taskbar**、**Start Menu**、
**Minimize**、右鍵選單與改名，視窗位置在下次開啟時還原。

不在範圍：**Taskbar** 移位與調整大小（B21）、**Machines Folder**（B15）、檔案管理（B16）、遠端（B22）。

## 2. 現況與限制（已查證）

| 事實 | 出處 | 影響 |
|---|---|---|
| `tab list` 的 `TabInfo` 沒有 root pane；只有 `tab create`/`workspace create` 的回應帶 `root_pane` | `src/api/schema/tabs.rs` `TabInfo`；`src/api/schema/response.rs` | 對既有的 tab（herdr TUI 開的、重開 desk 時），desk 無法從公開 API 得知 root pane。見 §6 決策 1 |
| `pane list` 依版面順序列出 pane（`tab.layout.pane_ids()`） | `src/app/creation.rs` `collect_panes_for_workspace` | herdr-sidebar 的 `Sidebar` pane 在左側時排第一，不能用「第一個 pane」代替 root pane |
| 有 `workspace list/create/rename/close`、`tab list/create/rename/close` CLI | `herdr workspace --help`、`herdr tab --help` | **Task**/**Window** 的新增、改名、關閉都走公開 CLI |
| Session 資料目錄 | `src/session.rs` `data_dir()` | 視窗狀態存在 `<data_dir>/desk.json`，每個 Session 各一份 |

## 3. 功能規格

| 項目 | 行為 |
|---|---|
| **Task** | Session 中每個 workspace 一個 **Taskbar** 按鈕，顯示名稱與視窗數；聚焦視窗所屬的 **Task** 反白 |
| **Task** 按鈕左鍵 | 跳出該 **Task** 的視窗清單（最小化的標記出來）；點選即還原並置頂 |
| **Task** 按鈕右鍵 | 改名（`workspace rename`）、在此 **Task** 新增視窗、全部最小化、全部還原、關閉 **Task**（`workspace close`，先確認） |
| 標題列按鈕 | `[_]` 最小化、`[□]` 最大化/還原、`[×]` 關閉（`tab close`） |
| 標題列右鍵 | 改名（`tab rename`）、最小化、最大化/還原、關閉 |
| 改名對話框 | 單行輸入，Enter 確定、Esc 取消；沿用 wens-tui-lab `dialog.rs` 的框與按鈕列 |
| **Start Menu** | **Taskbar** 最左的按鈕：新增視窗（在聚焦的 **Task**）、新增 **Task**（`workspace create`）、排列全部、離開；B15 起加入 **Machines Folder** |
| 鍵盤 | 前綴 Ctrl+\ 保留為備用：`n` 新視窗、`w` 關閉、`m` 最大化、`z` 最小化、`t` 排列、`Tab` 切換、`q` 離開、Ctrl+\ 送出字面值 |
| 與 server 同步 | 每秒以 `workspace list` + `tab list` + `pane list` 輪詢一次；herdr TUI 或其他 **Client** 新增、改名、關閉的 workspace/tab 會出現在 desk 上 |
| 狀態保存 | `<data_dir>/desk.json`：以 terminal id 為鍵，存視窗位置、大小、最大化、最小化、z-order；開啟時還原，找不到的視窗依序疊放 |

## 4. 程式結構

沿用 B13 的位置（`src/cli/desk/`），在 `main` 上新開分支 `b14-desk-shell`，完成後合併回 `main`。

| 檔案 | 內容 |
|---|---|
| `src/cli/desk.rs` | 入口與用法（自 spike） |
| `src/cli/desk/wm.rs` | 視窗幾何、z-order；新增最小化狀態 |
| `src/cli/desk/server.rs` | 公開 CLI 呼叫：列出、建立、改名、關閉 workspace/tab；輪詢結果比對（新） |
| `src/cli/desk/stream.rs` | 每視窗一條 `terminal session control` 子程序（自 spike 的 `session.rs`） |
| `src/cli/desk/taskbar.rs` | **Taskbar**、**Start Menu** 按鈕的版面與點擊判定（新） |
| `src/cli/desk/menu.rs`、`dialog.rs` | 彈出選單、改名對話框（移植自 wens-tui-lab `menu.rs`、`dialog.rs`） |
| `src/cli/desk/state.rs` | `desk.json` 讀寫（新） |
| `src/cli/desk/app.rs` | 事件迴圈、輸入分流、組合畫面 |
| `src/pane/desk_mirror.rs` | 自 spike，不變 |
| `src/platform/windows.rs` | 接收 spike 的 Windows VT 輸入函式（`#[cfg(windows)]` 債務） |

Upstream 掛接點：`src/cli.rs` 2 行、`src/pane.rs` 1 行、`src/platform/windows.rs` 1 個函式；決策 1 選 A 時再加 §6 所列兩處。

## 5. 不做

- 視窗在 **Task** 之間搬移（等於 herdr 的 pane/tab 移動，之後再評估）。
- 分割 pane 的顯示：tab 內其他 pane 不顯示，但標題列顯示「+N panes」提示。

## 6. 決策（owner 2026-10-25 核准，皆採建議）

1. **既有 tab 的 root pane 如何取得**
   - **採用 A**：在 `TabInfo` 加選填欄位 `root_pane_id`（`src/api/schema/tabs.rs` 1 欄位、`src/app/creation.rs` `tab_info` 1 行）。符合「新欄位須選填」的相容規則；舊版 server（例如遠端未更新的 herdr）沒有這欄時，退回第一個沒有 plugin 標記的 pane。可考慮之後提給 upstream。
   - B：不改 upstream，只靠推測：desk 自己建立的 tab 記下 root pane；其他 tab 取版面順序中第一個沒有 plugin 標記（label、`herdr-sidebar-*` token）的 pane。可能選錯。
2. **Windows**：B14 驗收是否包含 Windows？
   - **採用**：不含，留在 V2。若要含，需你同意在這台 Mac 執行 `just setup-windows-cross`（接受 Microsoft SDK 授權）。

### 效能（release binary，200×60，每視窗 `seq`，隔離 server，20 秒，`desk_perf.py`）

| 視窗數 | desk CPU | server CPU（無 → 有 desk） | frame/s | frame KiB/s | 繪製平均 / 最大 | B13 desk CPU |
|---|---|---|---|---|---|---|
| 1 | 2.7% | 100.3% → 101.0% | 54 | 18 | 0.29 / 0.68 ms | 1.8% |
| 15（排列） | 12.3% | 429.6% → 443.1% | 750 | 138 | 1.37 / 1.64 ms | 10.8% |
| 15（疊放 84×26） | 19.5% | 429.4% → 446.7% | 733 | 223 | 2.84 / 3.61 ms | — |

- 比 B13 多約 1 個百分點：每秒輪詢的三個 CLI 子程序（desk CPU 含回收的子程序）。
- 疊放那列是有 `desk.json` 時新視窗不排列、以 84×26 疊放的結果：視窗大、frame 多，成本隨畫面面積成長，不是退步。

### 留下的問題

- 狀態只在離開時存檔；desk 異常結束會遺失該次調整。
- 每秒 3 個子程序輪詢；之後可改用 `events.subscribe`。
