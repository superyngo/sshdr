# B13 桌面技術驗證（spike）計畫
Status: Landed — 結果見 [B13 spike 結果](../audit/2026-10-24-b13-desk-spike.md)

Source: [ADR 0006](../adr/0006-tui-desktop-as-separate-client.md)；[評估](../audit/2026-10-24-desktop-env-assessment.md)；Backlog B13

## 1. 目標

在真實執行的程式上驗證：每個 **Terminal Window** 一條 `terminal session control` 串流、由 **Desktop**
自己組合畫面，這個做法在互動、效能、斷線重連上都可行。結論決定 B14 的串流方式與 Windows 是否留在第一版。

## 2. 前置

- Zig 0.16.0 已安裝（`/opt/homebrew/bin/zig`）。先在 `main` 跑 `just check` 當基準，結果回填 Backlog V1。

## 3. 串流介面（現況）

`src/client/terminal_sessions.rs`：

| 方向 | 格式 |
|---|---|
| 送入（stdin，一行一個 JSON） | `terminal.input`（`text` 或 base64 `bytes`）、`terminal.resize`（`cols`、`rows`）、`terminal.mouse`（`down/up/drag/move`、按鍵、`column`、`row`）、`terminal.scroll`、`terminal.release` |
| 收回（stdout，一行一個 JSON） | `terminal.frame`（`seq`、`width`、`height`、`full`、base64 ANSI `bytes`）、`terminal.closed` |

鍵盤輸入是原始位元組；按鍵轉位元組由 **Desktop** 負責。

## 4. 實作步驟

| # | 步驟 | 驗證 |
|---|---|---|
| 1 | 新增 sshdr 自有模組 `src/desk/`。Upstream 掛接點只有兩處：`cli.rs::maybe_run` 的 `"desk"` 分支與模組宣告 | `git diff master -- src/cli.rs src/main.rs` 只有這兩處 |
| 2 | 串流：每個視窗一個 `herdr terminal session control <terminal_id> --cols --rows` 子程序，stdin/stdout JSON。不改 herdr 內部程式。效能不足時，B14 改程序內連線（需把 `connect_terminal_session_stream` 改為 `pub(crate)`） | 單一視窗能顯示 shell 並回應輸入 |
| 3 | 建立 pane：以 JSON API（`workspace.create`、`tab.create`）在專屬的 `desk` workspace 中每個視窗開一個 tab，取得 `terminal_id` | `herdr workspace list` 看得到 `desk` |
| 4 | ANSI → 畫面：每個視窗一個 `ghostty_vt::Terminal`，`full` 時重置；格子複製到 ratatui `Buffer`。能沿用 server 的終端轉 Buffer 程式就沿用，否則寫轉接層 | `Buffer` 斷言單元測試 |
| 5 | 最小視窗管理：搬 `~/repos/wens-tui-lab` 的 `desk.rs`、`hitmap.rs`、`geom.rs`。點擊置頂、標題列拖曳、邊框縮放、左右半邊與頂端最大化 **Snap**；縮放時送 `terminal.resize` 並調整本地 `Terminal` | 幾何與點擊判定單元測試 |
| 6 | 輸入：標題列與邊框的滑鼠由 **Desktop** 處理；視窗內容的滑鼠換算成視窗內座標送 `terminal.mouse`；鍵盤原始位元組轉給聚焦視窗；保留桌面快捷鍵（新增視窗、離開） | `htop`/`vim` 滑鼠可用 |
| 7 | 斷開與重連：離開後 pane 留在 server；再次執行 `herdr desk` 時掃描 `desk` workspace 的 tab 重建視窗 | 離開後重進，視窗內容仍在 |

不在範圍：**Taskbar**、**Start Menu**、視窗幾何持久化（B14）。

## 5. 驗證

| 項目 | 方法 |
|---|---|
| 互動 | 沿用 wens-tui-lab `scripts/pty_drive.py`：開 3 個視窗、拖曳、縮放、**Snap**、shell 輸入 `ls`、`htop`/`vim` 滑鼠、離開後重連，截圖比對 |
| 效能 | 1 vs 15 個持續輸出（`yes`）的視窗，報告每幀合成時間與 CPU（AGENTS.md「Multiplicative performance paths」） |
| 單元 | 視窗幾何、點擊判定、ANSI → `Buffer` |
| Windows | `just windows-lint` 只證明能編譯；能否使用需在 Windows 機器上實跑。沒有機器時記為「已能編譯、尚未實際驗證」 |
